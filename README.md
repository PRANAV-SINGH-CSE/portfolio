## 🌟 Featured Engineering Projects

1. **[Sprinto (SyncBoard)](https://sprinto-move.vercel.app/)**
   - *Real-Time Collaborative Workspace & Kanban Platform*
   - Sub-1ms optimistic UI updates with `@dnd-kit`, ~4.5ms median multi-client WebSocket synchronization via Firestore, and ~5ms repeat-visit loads with IndexedDB caching.

2. **[Review Radar](https://review-radar-virid.vercel.app/)**
   - *AI-Powered E-Commerce Review Intelligence & Sentiment Analysis Engine*
   - Next.js 16 App Router, React 19, Google Gemini 2.5 Flash strict JSON schema enforcement, Prisma ORM v6, MongoDB Atlas, and JWT (jose) Edge Middleware with AES-256.

3. **[ZentiqAI](https://zentiqai.vercel.app/)**
   - *AI Chat Web Application with Persistent Multi-Session Concurrency*
   - Python (Flask) backend concurrency, cross-device Firestore state persistence, and modular class-based client architecture.

4. **[LiveVoice AI](https://github.com/PRANAV-SINGH-CSE)**
   - *Real-Time Speech Intelligence & Desktop HUD Platform*
   - Sub-700ms voice loop, 0.28x real-time factor Faster-Whisper ASR, ~197 tokens/sec streaming, and always-on-top transparent PyQt5 overlay.

## 🚀 Tech Stack

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion, `@dnd-kit`, IndexedDB.
- **Backend & APIs**: Python, FastAPI, Flask, Node.js, REST APIs, WebSockets.
- **Databases & ORMs**: Firebase (Firestore, Realtime DB, Auth), MongoDB Atlas, Prisma ORM v6, MySQL.
- **AI & Speech**: Faster-Whisper, Gemini 2.5 Flash, Claude & OpenAI APIs, Prompt Engineering.

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/PRANAV-SINGH-CSE/portfolio.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
